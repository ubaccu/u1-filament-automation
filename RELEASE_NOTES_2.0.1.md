# U1 Filament Automation 2.0.1

Hotfix release for two issues found in U1FA 2.0.0.

- Fixed the Windows Adaptive PA setup error caused by CRLF conversion of protected assets.
- Fixed HTTPS certificate handling for Spoolman connections.
- Added additional Windows package validation to prevent protected asset corruption.

The Windows setup fix was confirmed with the 2.0.1 RC1 test build on a real user setup.

No changes to firmware compatibility or Adaptive PA calibration behaviour.
