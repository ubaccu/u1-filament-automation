# Supporto U1FA

**Italiano** | [English](SUPPORT.md)

Grazie per contribuire a migliorare U1 Filament Automation.

## Segnala un bug

Usa il modulo **Bug report** su GitHub:

https://github.com/ubaccu/u1-filament-automation/issues/new/choose

Prima di aprire una segnalazione:

1. Aggiorna U1FA all'ultima release disponibile.
2. Riproduci il problema solo se è sicuro farlo.
3. Annota la versione esatta di U1FA e il sistema operativo.
4. Se il problema riguarda calibrazione o configurazione stampante, indica anche versione firmware U1 e versione Snapmaker Orca.
5. Allega screenshot o log ripuliti quando sono utili.

Descrivi sempre:

- cosa stavi cercando di fare;
- cosa ti aspettavi che succedesse;
- cosa è successo realmente;
- se il problema è riproducibile;
- se U1FA aveva già scritto su Spoolman, Orca o sulla stampante prima del problema.

## Non pubblicare segreti o dati sensibili

Non inserire password SSH, token, chiavi private, archivi completi di configurazione, dati personali o log non ripuliti che contengano credenziali. Gli indirizzi IP privati/locali normalmente non servono per una segnalazione bug e, quando possibile, vanno rimossi dagli screenshot.

Per una vulnerabilità di sicurezza segui [.github/SECURITY.md](.github/SECURITY.md) invece di aprire una Issue tecnica pubblica.

## Richieste di nuove funzioni

Usa il modulo **Feature request** nelle GitHub Issues. Le richieste dovrebbero restare nell'ambito di U1FA: gestione filamenti Snapmaker U1, Spoolman, Snapmaker Orca, calibrazione, sicurezza e distribuzione dell'app.

## Ambito del supporto

Il progetto supporta l'ultima release U1FA pubblicata. L'installazione dei file sulla stampante è volutamente prudente: firmware o hash file sconosciuti possono essere bloccati finché non vengono validati. Un firmware sconosciuto bloccato è una protezione di sicurezza, non un motivo per aggirare manualmente i controlli.

U1FA è software community indipendente. Il supporto viene fornito nei limiti del possibile e non sostituisce il supporto ufficiale Snapmaker né quello dei manutentori di Spoolman, OrcaSlicer, Klipper o Moonraker.
