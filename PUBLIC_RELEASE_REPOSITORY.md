# U1FA public release channel

This repository is the official public **distribution, documentation and support** channel for **U1 Filament Automation (U1FA)** by Bottega3DLab.

Development is maintained separately. Public releases provide installers for supported platforms, `SHA256SUMS.txt`, and a version-matched GPL corresponding-source archive. Historical release tags are retained as immutable references for distributed versions and their corresponding source snapshots.

Normal bugs and feature requests are tracked through GitHub Issues. Security-sensitive reports should follow `.github/SECURITY.md` and must not expose credentials or confidential data in public issues.

# Canale pubblico U1FA

Questo repository è il canale pubblico ufficiale per **distribuzione, documentazione e supporto** di **U1 Filament Automation (U1FA)** di Bottega3DLab.

Lo sviluppo viene mantenuto separatamente. Le release pubbliche includono installer per le piattaforme supportate, `SHA256SUMS.txt` e l'archivio del sorgente GPL corrispondente alla stessa versione. I tag storici vengono mantenuti come riferimenti immutabili delle versioni distribuite e dei relativi snapshot sorgente.

Bug normali e richieste di nuove funzioni vengono gestiti tramite GitHub Issues. Le segnalazioni di sicurezza devono invece seguire `.github/SECURITY.md` e non devono esporre credenziali o dati riservati in Issue pubbliche.
