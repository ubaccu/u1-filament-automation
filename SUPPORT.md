# U1FA Support

[Italiano](SUPPORT.it.md) | **English**

Thank you for helping improve U1 Filament Automation.

## Report a bug

Use the GitHub **Bug report** form:

https://github.com/ubaccu/u1-filament-automation/issues/new/choose

Before opening an issue:

1. Update to the latest U1FA release.
2. Reproduce the problem if it is safe to do so.
3. Note the exact U1FA version and operating system.
4. If the issue involves calibration or printer setup, also note the U1 firmware version and Snapmaker Orca version.
5. Add screenshots or sanitized logs when useful.

Please describe:

- what you were trying to do;
- what you expected to happen;
- what actually happened;
- whether the issue is reproducible;
- whether U1FA wrote to Spoolman, Orca or the printer before the problem appeared.

## Do not post secrets or sensitive data

Do not include SSH passwords, access tokens, private keys, complete configuration archives, personal data, or unredacted logs containing credentials. Private/local IP addresses are normally unnecessary for bug reports and should be removed from screenshots when possible.

For a security vulnerability, follow [SECURITY.md](SECURITY.md) instead of opening a public technical issue.

## Feature requests

Use the **Feature request** form in GitHub Issues. Keep requests focused on U1FA's scope: Snapmaker U1 filament management, Spoolman, Snapmaker Orca, calibration workflow, safety and application distribution.

## Support scope

The project supports the latest published U1FA release. Printer-file installation is intentionally conservative: unknown firmware or file hashes may be blocked until they are validated. A blocked unknown firmware state is a safety feature, not a reason to bypass checks manually.

U1FA is independent community software. Support is provided on a best-effort basis and does not replace support from Snapmaker or the maintainers of Spoolman, OrcaSlicer, Klipper or Moonraker.
