# U1 Filament Automation 2.0.6

This hotfix completes the language cleanup in the searchable calibration filament picker.

- In **IT**, the search field now shows only **“Cerca filamento…”**.
- In **EN**, the search field now shows only **“Search filament…”**.
- The empty-search message is also language-specific: **“Nessun filamento trovato”** in IT and **“No filament found”** in EN.
- The alphabetical A → Z ordering and Spoolman colour display introduced in 2.0.5 are unchanged.
- No changes were made to Adaptive PA, Orca profile handling, Spoolman write logic, printer firmware compatibility or PAXX support.
