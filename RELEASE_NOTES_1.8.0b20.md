# U1 Filament Automation 1.8.0b20

## Home and first setup

- Replaces the old private-beta warning card with a clear first-printer-setup notice.
- Adds a direct **Check printer setup / Controlla configurazione stampante** button before filament actions.
- Reminds users to run the printer setup check before the first calibration and again after every U1 firmware update.
- Keeps the compact grouped home introduced in b19.

## Support U1FA

- Adds an in-app **Buy me a coffee** support card linked to the official Bottega3DLab page.
- Uses a locally styled button in the desktop app, so opening U1FA does not load the external Buy Me a Coffee image CDN.
- Adds the official Buy Me a Coffee button to the English and Italian GitHub READMEs.
- Adds `.github/FUNDING.yml` so GitHub can expose the repository Sponsor link.

## Safety

This release changes presentation and navigation only. It does not automatically modify the printer, Snapmaker Orca profiles, Spoolman data, Adaptive PA configuration or firmware.
