U1 Filament Automation - LEGGIMI PRIMA

Questa versione di U1FA non è notarizzata da Apple. macOS può quindi bloccare il primo avvio anche se l'app è stata scaricata dalla release ufficiale.

Installazione su macOS

  1. Trascina U1 Filament Automation nella cartella Applications.
  2. Apri Applications, fai clic destro su U1 Filament Automation e scegli Apri.
  3. Se compare una nuova finestra di conferma, scegli ancora Apri.
  4. Se macOS continua a bloccare l'app, vai in Impostazioni di Sistema → Privacy e sicurezza, scorri fino al messaggio relativo a U1 Filament Automation e premi Apri comunque. Conferma quando richiesto.

Non disattivare Gatekeeper e non usare comandi Terminale per rimuovere le protezioni di macOS. È sufficiente autorizzare questa app con i passaggi sopra.

Nota: l'autorizzazione serve normalmente solo al primo avvio della specifica applicazione scaricata.
