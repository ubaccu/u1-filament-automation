U1 Filament Automation - README FIRST

This version of U1FA is not notarized by Apple. macOS may therefore block the first launch even when the app was downloaded from the official release.

Installation on macOS

  1. Drag U1 Filament Automation to the Applications folder.
  2. Open Applications, right-click U1 Filament Automation and choose Open.
  3. If another confirmation window appears, choose Open again.
  4. If macOS still blocks the app, open System Settings → Privacy & Security, scroll to the message about U1 Filament Automation and click Open Anyway. Confirm when prompted.

Do not disable Gatekeeper and do not use Terminal commands to remove macOS protections. Authorizing only this app with the steps above is enough.

Note: this authorization is normally required only on the first launch of the downloaded application.
